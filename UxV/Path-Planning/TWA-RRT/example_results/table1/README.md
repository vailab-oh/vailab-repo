# Historical aggregate examples

> The public benchmark IDs now use descriptive names. These historical CSVs and selected_runs.json intentionally retain their original IDs and run provenance. Map them to current IDs using ../../docs/BENCHMARK_SELECTION.json; new executions use the renamed output directories.

The three-case CSVs were copied from the final historical comparison batch (20260913_201511_595523). Only the WISER display label was changed to TWA-RRT*. Numerical values were preserved. selected_runs.json preserves the original run IDs, trials and seeds without local paths. early_arrival_core_metrics.csv is regenerated by the unchanged comparison rules from the completed historical M5 100-trial batch.

No large raw trials, local paths, full config manifests or manuscript sources are bundled. These files are not new 100-trial experiments, and are not an automatically corrected Table 1. See ../../docs/MANUSCRIPT_CROSSCHECK.md for swapped case labels and HPO metric populations. Full raw histories must be supplied separately to reaggregate the identical historical run selection without replaying experiments.
