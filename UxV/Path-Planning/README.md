# Path Planning

Research resources for path and motion planning methods for unmanned vehicles.

## Projects

### [TA-RRT*](TA-RRT/)

Terrain Analysis–Rapidly exploring Random Tree* combines terrain-guided adaptive
sampling with adaptive step sizing for path planning in complex environments.
The project includes a reusable Python package, command-line demo, tests, result
visualization, and complete citation metadata.

Associated paper: [“TA-RRT*: Adaptive Sampling-Based Path Planning Using Terrain
Analysis”](https://doi.org/10.3390/app15052287), *Applied Sciences*, 2025.

### [TWA-RRT*](TWA-RRT/)

Time-Window-Aware Sampling-Based Path Planning for Time-Constrained Unmanned
Aerial Vehicle Missions. The project includes the TWA-RRT* implementation,
benchmark adaptations, experiment configurations, analysis tools, and example results.

**Associated paper: Accepted.** Journal, DOI, and final publication details will
be updated when available. See the [project README](TWA-RRT/README.md) for usage,
licensing scope, and reproducibility notes.
